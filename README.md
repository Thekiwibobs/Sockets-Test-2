This project is a simple chat room written in python that you can host or join.
The server can't see messages only people who joined.

Messages are unencrypted at the moment and probably won't be changed.

This project has very similar code to NeuralNine's "Simple TCP Chat Room in Python" video on youtube. Credits to him for the amazing tutorial check out his youtube here
